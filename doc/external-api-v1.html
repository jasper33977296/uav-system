01有哪些無人機可控

指令用 sysid（整數）定址無人機。這一支同時回答「哪些機在線」與「哪一台現在指得動」。

GEThttp://10.141.2.21:38001/api/ext/drones

機隊清單。controllable 是 true 才可以對它下指令。

payload

keyvalue資料格式
none

回應

200
{
  "drones": [{
    "sysid": 1,                     // 指令都用這個號碼定址
    "name": "pi5-sdmodelh7v2-ardu",
    "online": true,                 // 心跳還在
    "age_s": 0.0,                   // 距最後一則心跳的秒數
    "armed": false,
    "controllable": true            // false 時會多一個 reason 說明是什麼擋住
  }]
}

02有哪些規劃檔

所有可用的航線都在任務庫裡——前端規劃的、匯入的、從機上讀回的都會存進來。清單回的 id 就是後面上傳與執行要用的 mission_id。

GEThttp://10.141.2.21:38001/api/missions

可以飛的航線清單。

payload

keyvalue資料格式
none

回應

200
{
  "missions": [{
    "id": "de58a69b-a418-4a08-a08e-58009c50a457",
    "name": "circle-ardupilot-fence-rally",
    "nav_count": 4            // 帶座標的航點數
  }]
}

03上傳規劃檔到無人機

POSThttp://10.141.2.21:38001/api/command/{sysid}/mission/upload

把任務庫的一份航線寫進飛控，並逐項讀回比對。

payload

keyvalue資料格式
mission_id"de58a69b-a418-4a08-a08e-58009c50a457"string · 必填

回應

200
{
  "uploaded": 7,        // 寫進飛控的航點數
  "verified": true      // true 才算上傳成功
}

飛行中不能上傳。飛控收到新航線的那一刻就會照它飛，所以機在空中執行任務時這支會回 409。要在空中換航線，先用 §6 切 hold 懸停，再上傳。

04執行任務

一般用 /api/start 一支就好：上傳 → 解鎖 → 起飛 → 開始飛任務，每步確認過才往下走。

POSThttp://10.141.2.21:38001/api/start

從地面直接起飛執行一份航線。

payload

keyvalue資料格式
mission"de58a69b-a418-…" 或 "circle-ardupilot"string · 必填
任務庫的 id 或 name
sysid1int · 選填
只有一台在線時可省略
takeoff_alt5float · 選填（公尺）
省略＝跟著航線自己的起飛高度

回應

200
{
  "ok": true,           // true = 已經在飛任務
  "sysid": 1,
  "mission_id": "de58a69b-a418-…",
  "name": "circle-ardupilot-fence-rally"
}

失敗時回 4xx／5xx，body 的 steps 會說明停在哪一步，機體停在安全狀態（懸停或還在地面）。

POSThttp://10.141.2.21:38001/api/command/{sysid}/mission/start

只在機已經解鎖並在空中時用：叫它開始飛機上現有的那份任務。地面上的機請用上面那支。

payload

keyvalue資料格式
none

回應

200
{"accepted": true}

05拿訊號資料

用 /api/ext/live 輪詢。伺服器端每秒更新，輪詢頻率建議 1–5 次/秒，再高也拿不到更新的資料。

GEThttp://10.141.2.21:38000/api/ext/live

即時快照：訊號、經緯度、高度、速度。
預設回主機那一台；要指定機體加 ?sysid=1。

payload

keyvalue資料格式
none

回應

200
{
  "drone_name": "pi5-sdmodelh7v2-ardu",
  "mav_sysid": 1,
  "connected": true,
  "armed": false,
  "lat": 25.055412, "lon": 121.506537,
  "alt_rel": 6.19, "alt_msl": 0.02,
  "ground_speed": 0.01, "vertical_speed": 0.01, "heading": 252.8,
  "telem_age_s": 0.4,          // 這些數字幾秒前收到的
  "link_state": "ok",
  "link_age_s": 1.2,           // 訊號量測幾秒前收到的
  "link": {
    "time": "2026-09-07T04:54:35.572369Z",
    "rsrp": -72.0, "rsrq": -10.5, "sinr": 29.5, "cqi": null,
    "pci": 85, "cell_id": 2179073, "band": "n79", "nr_mode": "SA",
    "rtt_ms": 28.5, "jitter_ms": null, "packet_loss_pct": null,
    "throughput_up_kbps": null, "throughput_down_kbps": null
  }
}

訊號指標（link 物件）

key單位意義
rsrpdBm參考訊號接收功率（訊號多強）
rsrqdB參考訊號接收品質
sinrdB訊號干擾雜訊比
cqi0–15通道品質指示
pci—Physical Cell ID（會重複，只在鄰區內唯一）
cell_id—全域 cell 識別碼（NCI/CGI）
band—頻段，如 n79
nr_mode—SA / NSA / LTE
rtt_msms來回時間
jitter_msms抖動
packet_loss_pct%封包遺失率
throughput_up_kbpskbps上行吞吐
throughput_down_kbpskbps下行吞吐
timeISO 8601這筆量測的採樣時刻

量測不到的欄位是 null，不會補假值。link_age_s 太大代表量測送不回來，這與「訊號很差」是兩件事。

位置、高度、速度

key單位意義
lat / lon十進位度WGS84；null = 尚未定位
alt_relm相對起飛點高度
alt_mslm海拔高度
ground_speedm/s對地速度
vertical_speedm/s垂直速度（正 = 上升）
heading度機頭方位，0 = 正北
telem_age_s秒這些數字多舊。斷線時數值不會消失，只會變舊

06中斷任務

POSThttp://10.141.2.21:38001/api/command/{sysid}/mode/{mode}

中斷任務。mode 寫在網址裡：hold 原地懸停（可續飛）、rtl 返航降落、land 就地降落、mission 繼續飛任務。

payload

keyvalue資料格式
none

回應

200
{"mode_engaged": true}   // true 才代表飛機真的切過去了

07失敗時的狀態碼

失敗一律回 4xx／5xx，body 的 detail.msg 是可以直接顯示給人看的原因。

狀態意思怎麼辦
403這台機不接受指揮，或系統的指令功能沒開先查 §1 的 controllable 與 reason
404找不到這份任務／航線檔用 §2 重新取清單
409當下狀態不允許（例如飛行中上傳、機在地面卻叫它開始任務）照 msg 的指示換做法
422payload 欄位缺漏或型別不對對照該端點的 payload 表
501這個機型的這個動作尚未支援換動作或換機
502 / 504指令送不到飛機（鏈路問題）可重試；連續失敗代表通訊中斷
503沒有任何無人機在線查 §1
