# Design Tokens — 全站視覺重整基準（v1）

- 狀態：**定稿供實作**（UI/UX 2026-08-11；使用者指定參考 Claude 前端風格）
- 依據：使用者六點回饋（經 PM 彙整）、doc/frontend.md 誠實原則、
  dataviz 方法（色盤數據全部過 validator，紀錄見文末）
- 實作對口：globals.css `:root` tokens（狀態語意變數沿用 09c974f 的
  `--status-*` 命名）＋ TS 內資料色盤

## 基調

參考 Claude 前端風格的四個可移植特質，套用在**深色預設**（2026-08-04
定案不變）上：

1. **暖中性**取代冷藍黑——所有灰階帶暖（stone 系），畫面不再「機房感」。
2. **層次靠明度差與髮線**，不靠陰影——浮動面板才有唯一一層柔影。
3. **圓角放軟**（卡片 10px、浮動面板 14px），**留白放寬**（間距階提高一級）。
4. **單一強調色**（珊瑚 terracotta）只給互動元素，畫面其餘保持低彩度——
   彩色只留給資料（軌跡/圖表/狀態），這與既有「彩色只出現在狀態圓點與
   軌跡」原則同向，等於把 Claude 的 calm 語言疊在我們的誠實原則上。

### 強調色使用鐵則（約束條款，PM 核可 2026-08-11——破例即設計違規，review 必擋）

珊瑚 `#d97757` 與狀態橘 `#e05e0e` 實測 ΔE 僅 6.1（CVD 5.4）——**肉眼與
色覺障礙都會混**。因此：

- accent **只出現在互動 chrome**（按鈕、連結、active 態、focus ring）。
- accent **禁止進入**地圖繪圖區、圖表繪圖區、狀態 chip、事件圓點——
  這些區域的暖色（橘/紅）永遠是狀態語意。
- 危險/緊急按鈕維持既有紅系（`--status-danger`），不改珊瑚。

### 狀態語意色（`--status-*`，沿用 09c974f 命名，值不變）

`--status-ok #0ca30c`、`--status-warn #fab219`（＋`--status-warn-bg
rgba(250,178,25,0.10)`，僅觀察橫幅等警告底用，20c712d 新增）、
`--status-serious #e05e0e`、`--status-danger #e05e5e`
（含 bg/border 變體照舊）。狀態色永遠配
圖示＋文字，不單獨傳達語意（既有原則）。

## 資料色盤（TS 內，附驗證）

### SINR 分級（軌跡，lib/signal.ts）——**值不變**

`#0ca30c / #fab219 / #e05e0e / #a01818`，門檻與 backend 事件一致。
新暖畫布 `#1b1a17` 重驗：CVD 全過（worst 11.3）、normal floor 過（19.1）。
**已知限制**：瀕斷 `#a01818` 對畫布 2.19:1（<3:1，換亮紅會撞劣化橘，
ΔE 崩到 8.8–12，取捨後保留深紅）。Relief（validator 要求的輔助管道）：
瀕斷必伴隨 link 事件流卡片＋側欄 SINR 數值分級標籤＋回放圖表事件標記，
顏色從不是唯一訊號。

**☐ P2 驗收 checklist 項（PM 指示，不可漏）**：圓管光照落地後重目測
瀕斷段在暖畫布上的可辨識度；若仍不過，**直接實作瀕斷段亮色描邊**
（幾何層，不動色盤），無需再議。

### 圖表序列（compare，SERIES）——**值不變，用法改**

深色列 `#3987e5 #d95926 #199e70 #c98500 #d55181 #008300` 在新 surface
`#262624` 重驗全過（CVD worst 8.4、normal 19.3、對比全 ≥3:1）。
使用者「多線難區分」的根因不是色值，是**多線交錯屬 all-pairs 情境，
本色盤只有前 3 槽通過 all-pairs**。因此規則改為：

- **同時高亮上限 3 條**；選超過 3 條時，其餘退為 `--muted` 細線＋
  線尾直接標名，hover/點擊才升為高亮（換色不換序——顏色跟航線，
  不跟排名）。
- 淺色主題用色盤的淺色列（`#2a78d6 #eb6834 #1baf7a …`），切換時同槽對應。

### 機隊識別（droneLayer DRONE_PALETTE）——**重定**

原六色在新畫布驗證失敗（藍↔紫 protan ΔE 4.8、粉↔駝 normal 14.1）。
改為沿用圖表序列的前三槽 `#3987e5 #d95926 #199e70`（all-pairs 驗證通過，
identity 與 status 依舊不互相冒充），第 4 機起色相循環停止、
靠既有 sysid chip 文字標籤區分（chip 是常駐的 secondary encoding；
群飛 >3 機的識別設計等 013 群組任務時另出）。

## 字階與間距

- 字體：系統 sans 全站不變（圖表含 hero 數字同）。Claude 的襯線
  display 面**不採用**——密度高的操作介面，襯線只會出現在品牌字
  「UAV 監控」一處，收益不足，不引入第二字族。
- 字階（px）：11（輔助）/ 12（標籤）/ 13（本文，基準）/ 15（小標）/
  18（卡片標題）/ 22（hero 數字如 SINR 大字）。行高 1.5，數字欄位
  `tabular-nums`。
- 間距階：6 / 10 / 14 / 20 / 28（原 4/8/12/16/24 各升約一級——
  「留白放寬」的具體落點；卡片內距 14、卡片間距 14、區塊間距 20）。
- 圓角：控制元件 6、卡片 10、浮動面板 14。
- 陰影：僅浮動面板（任務控制、圖例）一層
  `0 4px 16px rgba(0,0,0,0.35)`（深）／`rgba(26,25,21,0.12)`（淺）。

## 圖表樣式規範（回應不滿 1–3）

1. **降噪＝原始＋平滑並存**（PM 定案的形式，誠實原則）：原始樣本線
   降為 `--muted` 40% 透明 1px；疊加滑動平均平滑線 2px 主色；
   圖例標明「平滑（10s 窗）」與「原始」兩項。**禁止只畫平滑線。**
   顏色分級不插值。
2. 線寬 2px、標記 ≥8px、格線 `--hairline`、軸文字 `--muted`；
   雙圖共用時間軸（既有）維持**單一 y 軸**原則。
3. 圖例：≥2 系列必有圖例；≤4 系列同時做線尾直接標（超過就只留圖例）；
   文字一律 ink 色系，色彩由旁邊的色點承載。
4. Hover：時序圖 crosshair＋tooltip（時間、原始值、平滑值、分級標籤）。
5. 事件標記（回放/比較頁三角）：維持狀態色＋形狀，tooltip 出事件原文。

## 漸進揭露（回應不滿 5「解釋文字太多」）

- 面板常駐文字只留**行動必需**：按鈕、數值、狀態。
- 說明文（如手動控制的 deadman 解說、ENABLE_COMMANDS 教學）收進
  「?」icon 的 popover 或摺疊列，預設收合；例外：**安全警示橫幅**
  （僅觀察鎖定、失聯）不收合——安全資訊不做漸進揭露。
- 摺疊記憶判準（2026-08-11 補）：**教學文不記憶展開狀態**（重讀成本低，
  常收合保持乾淨）；**工作區資訊記憶**（如 5G 詳細——研究者常駐使用，
  localStorage 記住展開）。
- 錯誤原文照舊全文顯示（失敗必須看得見，不裁切）。
