# 實體驗證查核表（可直接填）

> 逐項填四格：**日期／韌體／結果／證據**。結果只有三種，沒有「大概可以」：
> `PASS`（判準那欄寫的，親眼看到了）、`FAIL`（沒看到或看到別的，照失敗處置做）、
> `SKIP`（沒測——**skip ≠ pass**，沒測就是沒有證據，不得往下走）。
>
> 「證據」要能讓別人重看：截圖檔名、`data/conformance/*.json`、tlog 時間戳、
> 或 `journalctl` 的那幾行。**寫「看起來正常」不算證據。**
>
> 設計背景與每一項的理由見 [`real-aircraft-verification.md`](real-aircraft-verification.md)。
