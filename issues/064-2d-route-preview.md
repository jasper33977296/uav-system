# 064 · 控制端要看得到每條路徑的 2D 預覽圖

- 狀態：**closed**（2026-09-23）
- 嚴重度：low（可用性；但影響每天都會用到的挑路徑動作）
- 位置：`apps/frontend/components/MissionThumb3D.tsx`、
  `apps/frontend/app/plans/page.tsx`
- 建立：2026-09-21

## 現象與需求

希望控制端能看到**每條路徑的 2D 預覽圖**。

## 現況

已經有縮圖，但是**等距投影的 3D**（`MissionThumb3D`，ui-spec §4 B 案定案）：
固定 pitch 55°、可拖曳旋轉、零 WebGL 的 SVG 實作。它的目的是「近似即時頁觀感」。

3D 縮圖在**認出這是哪一條路徑**這件事上不好用：同一塊場地的幾條路徑，
在斜角投影下形狀彼此很像，而且每張卡的 bearing 可以被轉過，兩張卡之間
不一定同一個朝向。2D 俯視圖形狀穩定、彼此可比。

## 修法建議

* 加一個 2D 俯視模式（正射、北方朝上、固定朝向），與現有 3D 並存。
  `MissionThumb3D` 已經把「把 waypoints 投影進 SVG」做好了，2D 是它的特例
  （pitch 0、bearing 0），**不必另寫一套投影**。
* 決定預設哪一個。建議**列表頁預設 2D**（要比較與辨識），3D 留給單一路徑的
  細看。
* 2D 上要看得出：起點／終點、方向、以及 062 的停留點。
* 比例尺要可比——同場地的幾條路徑用同一個比例，否則形狀還是比不了。

## 相關

* 062（停留時間）——停留點要在預覽上看得出來
* 063（建物遮擋）——2D 俯視沒有這個問題，可以當成臨時的替代操作面

## 解決方式

`components/MissionThumb2D.tsx`：正射、**北方朝上、固定朝向、沒有互動**（要轉要看高低差
請用 3D 那張或進編輯頁）。規劃頁工具列一顆「縮圖：2D／3D」，**預設 2D**，選擇記在瀏覽器。

* **同場地同比例**：中心點相距 1.5 km 內算同一場地，整組用組內最大的半徑當比例
  ——所以小的路徑在卡片上就真的比較小，那是事實；左下角有比例尺（實測全列都是 20 m）。
* 看得出：起點（綠圓）／終點（方塊）、**方向**（每段中點一個箭頭）、
  **停留點**（空心環，062）、北方（N）。
* 停留資料來自 `/plans/{id}/waypoints` 新增的 `hold_s`（只採 `NAV_WAYPOINT` 的 param1）。

驗證（CDP）：13 張 2D 縮圖；兩條帶停留的航線各 3 個停留環、其餘 0；比例尺一致；
切換後變成 13 張 3D、0 張 2D。
（closed 時補）
