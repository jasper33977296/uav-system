## 使用者要求（2026-10-19）

> 系統斷線的話前端顯示資料像是訊號、即時畫面都要清掉，避免誤解還連著。

## 盤點：原本哪些會留著舊值

| 元素 | 原本 | 問題 |
|---|---|---|
| **與系統的連線斷掉（WS）** | 年齡停在最後一則 | `telem_age_s`／`link_age_s` 是後端送出時算的，斷了就沒人更新——所有「看年齡決定要不要拿掉數值」的地方都以為資料是新的 |
| 側欄訊號卡（SINR、RSRP、RTT、cell…）| **完全不看年齡** | 最後一筆以全亮大字一直留著 |
| HUD 訊號格、訊號變差／恢復 toast、無人機頁訊號格 | 看遙測年齡或不看 | 5G 樣本走代理、遙測走 MAVLink，各斷各的 |
| SINR 走勢、尾跡顏色 | 每則遙測（約 5Hz）都把最後一筆 SINR 塞進去 | 後端斷了也照附——畫成一條「訊號很穩」的平線 |
| IMU／姿態／座標 | 不看年齡 | 同上 |
| 代理鏡像 `fresh` | 代理沒斷線、只是不講話時停在 true | 後端只在收到 state 時廣播 |
| 即時影像（MJPEG）| 影格不來就停在最後一張 | `<img>` 不報錯、不觸發事件——和「鏡頭前沒東西在動」分不出來 |

## 做法

- **年齡在前端自己的時鐘上繼續長**：收到時記下後端給的年齡，之後每秒加上本地經過的時間
  （`tickAges`）。WS 斷了、或後端不再廣播某台機，年齡照樣變大，既有的拿掉規則就會生效。
  代理鏡像 5 秒沒有新的一則 → `fresh=false`（＝不知道）。
- 訊號一律看**訊號樣本自己的年齡**（`freshLink`）：> 10 秒拿掉數值、留一句「訊號在 N 分鐘前更新」；
  2–10 秒變淡。走勢與尾跡只收新鮮樣本。
- IMU 卡同 StatusCard 規則：遙測過舊就拿掉數值，只留過去式。
- 影像：MJPEG 每 1.5 秒問地面站 `/camera` 的 `last_frame_age_s`（**這個端點不會因為問就開轉碼**），
  > 3 秒或問不到 → 把畫面藏起來，說「影像中斷——最後一張是 N 秒前」，恢復後自己接上。
  `<video>`（WHEP）看播放時間有沒有前進（暫停／播完不算）。

**不改的**：地圖上的機身留在最後已知位置（已有紅色閃環＋「最後已知位置」toast——那是
「它最後在哪」的事實，找機要用）；尾跡保留歷史。
