# 057 · 代理的事件清單沒有人讀：18 處往裡面寫，0 處讀

- 狀態：open
- 嚴重度：medium（該讓操作員看到的事沒有送出去；附帶一個慢性記憶體成長）
- 位置：`uav-agent/agent.py`（`Monitor.events` 宣告與 18 處 `append`）、
  `uav-agent/intent.py:141`（**會動的那條路**）、
  `apps/backend/app/main.py:417`（`/ws/agent` 收 `event`）
- 建立：2026-09-21

## 現象

`agent.py` 的 `Monitor` 有一個 `self.events = []`，全檔 **18 處**往裡面丟東西：

| kind | 次數 | 例子 |
|---|---|---|
| `gs_link` | 5 | 地面站失聯／恢復（中斷幾秒）|
| `intent` | 4 | 改航線已確認、`{action} → {mode}` |
| `fs_gcs` | 2 | 飛控失聯 failsafe 自檢結果 |
| `takeover` | 2 | **代理接管開始／結束，期間做過什麼** |
| `statustext` | 1 | 飛控的 STATUSTEXT |
| `rc_link` | 1 | 遙控器在不在 |
| `guard` | 1 | 守門擋下了什麼 |
| `gs_link_action` | 1 | 失聯處置實際送了什麼指令 |

**沒有任何一行程式碼讀它。** 全庫只有 `.append`，沒有消費者、沒有序列化、
沒有人清它：

```
$ grep -rn "events" *.py | grep -vE "events\.append|self\.events = \[\]"
（只剩宣告那一行）
```

## 原因

不是「忘了送」那麼單純——**代理其實有一條會動的事件管道**，只是這個清單沒接上去。

`intent.py:141` 把事件經意圖通道送給地面站：

```python
self._send(ws, dict(self._pending.pop(0), type="event"))
```

而後端明確收這個型別（`main.py:417` 的 `/ws/agent`）：

```
收 `hello`／`state`／`event`／`ack`，反方向送 `intent`／`decision`／…
accepts: ["state", "event", "ack"]
```

所以管道是通的、後端也在等。`_pending` 由意圖處理函式的回傳值餵——
**而 `mon.events` 是另一條平行的、長得一模一樣的死路。**

## 影響

### 1. 該讓操作員看到的事，沒有送出去

最刺眼的是 `takeover`。那段程式自己的註解寫著：

> **接管結束要交代做過什麼。**「我不在的時候發生了什麼」是操作員回來第一個
> 要問的問題，而唯一答得出來的是代理

而那個答案被 append 進一個沒有人讀的清單。`gs_link_action`（失聯處置實際送了
什麼指令）同理——這是飛安相關的事實，只活在機上的記憶體裡。

**目前這些只能靠 journald 撈**：它們多半同時有 `log.warning`，所以不是完全
消失，但要 ssh 上機器 grep 才找得到，地面站與事後報告都看不到。

### 2. 看起來有、實際沒有

下一個人看到那 18 處 `append` 會合理推論「事件有被收集起來送到某處」，
於是做新功能時照著丟一筆。**2026-09-21 做 050 需求 1 時就差點這樣**——
原本打算照周圍程式的樣子 `mon.events.append(...)`，查了才發現丟進去等於沒做，
最後只留 `log.error`。

### 3. 慢性記憶體成長

清單只增不減。09-16 那天地面站鏈路每 30 秒抖一次（`gs_link` 一次失聯一次恢復），
光那一項就是每分鐘兩筆、每天約三千筆。代理是機上長跑的行程，不該有這種東西。

## 修法建議

先決定**要它還是不要它**，兩個方向都成立，不要留著現狀：

### A. 接上去（建議）

把 `mon.events` 接進既有的那條路——意圖通道的 `type: "event"`，後端已經在收。
要處理的：

- **節流與去重**。`gs_link` 在抖動的場域會狂噴，而 5G 抖動在本場域是常態
  （見 002 handover 事件抖動那次，最後整個型別被移除）。
- **斷線期間怎麼辦**：事件產生的時候往往正是送不出去的時候。要嘛沿用補傳
  （`Backfill`）那套緩衝＋確認的機制，要嘛明確決定「掉了就掉了」——
  但要決定，不要預設。
- 緩衝**必須有上限**，否則只是把現在的無限成長換個地方放。

### B. 刪掉

如果這些事 journald 就夠了，就把 18 處 `append` 與宣告一起刪乾淨。
**留著比刪掉糟**：它會持續誤導人，而且持續長大。

不論選哪個，順手把「事件要送到哪裡」寫進 `uav-agent/README.md`，
否則下一個人還是會重新發明一次這個清單。
