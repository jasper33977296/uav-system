# 013 · 群組任務：群飛以 group 概念同時配置飛行路徑

- 狀態：open
- 嚴重度：medium（研究願景功能；QGC 做不到的部分）
- 位置：`doc/gcs-replacement.md` §3（設計）；依賴 issue 012
- 建立：2026-08-10

## 需求

無人機群以「群組」為單位一次配置路徑並派發：群組上傳（逐台 ACK 矩陣）、
嚴格同時起飛、群組緊急 RTL。研究價值：N 台同測＝一次飛行取得鏈路品質
空間分布（垂直剖面／平面分割）。

## 定案要點

- 資料模型：`groups` ＋ `group_assignments`（group × drone × mission）；
  任務庫「路徑不綁機」不變（issue 010），group 是配置單位非擁有者
- 指派三式分版：V1 手動逐台 → V2 基準路徑＋自動偏移（同軌不同高，
  分層即去衝突）→ V3 區域自動分割
- 嚴格同時起飛＝**兩階段提交**：全組地面 arm（任一失敗→全組撤銷，
  零風險）→ 全成功才並行廣播 start；空中單台異常＝該台 RTL、其他繼續
- 去衝突是規劃期責任：高度分層（≥N m）／橫向分離檢查，不過不給上傳；
  **RTL 高度逐台錯開**（同高返航會在 home 上空匯合）
- 規模由小到大驗證：2–3 → 4–6 → 更多（時空檢查）；UI 逐台列表可滾動
- 方法學：多 UE 掛同 cell 互相影響鏈路品質——控制（量測期壓影像碼率）
  ＋記錄（cell_id/PCI 歸因），本身可為研究題目
