# 067 · 失聯時的前端呈現：時間寫法與那兩顆按不動的按鈕

- 狀態：**closed**（2026-09-22；「只有遙測斷、指令還通」那一支沒有實機重現，見〈解決方式〉）
- 嚴重度：low（呈現；但第二項會讓人在最糟的時刻按一顆沒有用的鈕）
- 位置：`apps/frontend/lib/staleness.ts:33`（`ageText`）、
  `apps/frontend/components/CommandPanel.tsx:1261-1273`（失聯區塊）
- 建立：2026-09-21

## 1. 失聯時間不要寫成「X.X 小時」

現況（`staleness.ts`）：

```ts
if (ageS < 3600) return `${Math.round(ageS / 60)} 分鐘前`;
return `${(ageS / 3600).toFixed(1)} 小時前`;     // ← 「7.4 小時前」
```

**要改成「幾小時幾分鐘」**——`7 小時 25 分前`，不是 `7.4 小時前`。

理由與這個函式自己既有的註解同一條：

> **超過一分鐘就用分鐘**——「185 秒前」要心算才知道多久。

`7.4 小時` 一樣要心算（0.4 小時是幾分鐘？），而且小數點會讓人誤以為那是個精確
量測。分秒制直接讀得出來。

## 2. 失聯時那兩顆按鈕要拿掉

現況（`CommandPanel.tsx`）：

```tsx
失聯——只剩返航與降落 ⋯
  {btn("RTL", "⌂ 返航", "/mode/rtl", …)}
  {btn("降落", "降落", "/mode/land", …)}
```

**使用者 2026-09-21：失聯的話這些按鈕也沒有作用，拿掉。**

這推翻了 2026-09-07 的裁定（那次的結論是「一句話＋兩顆鈕，其餘全收」）。
當時的理由寫在 tooltip 裡：「指令仍會送出，但送不送得到不知道」。現在的判斷是：
**一顆「按了也不知道有沒有用」的鈕，在最需要確定性的那一刻只會製造錯覺。**

### 實作時要一起看的（記下來，不是要翻案）

`linkLost` 的定義是 `live.connected === false`，而 `connected` 由**後端收到
MAVLink** 決定——也就是**下行**斷了。上行不一定同時斷：047 項次 6 實測過單向
中斷是真的存在（那次是反方向：一邊每秒送出九十幾則遙測，一邊宣告地面站失聯）。

所以在「下行斷、上行還通」的情況下，拿掉按鈕等於讓操作員失去一次**真的送得到**
的 RTL。這不是反對拿掉——是實作時應該順便決定：要不要用 `uplink_ok`
（機上已經在回報，見 047 項次 6）把這兩種失聯分開，只在**兩邊都斷**時才收掉按鈕。

文案也要跟著改：沒有按鈕之後，「只剩返航與降落」就不成立了。

## 解決方式

### 1. 時間寫法（`lib/staleness.ts` 的 `ageText`）

`N 秒前` → `N 分鐘前` → **`H 小時 M 分前`** → 超過一天 `D 天 H 小時前`。一律**無條件捨去**
（「59.6 分」寫成「60 分鐘前」下一秒又跳「1 小時前」很怪）。用在即時頁 HUD、側欄、
無人機管理頁、CommandPanel。12 個邊界值在前端容器的 node 裡跑過（含 `7.4 h → 7 小時 24 分前`）。

### 2. 按鈕：**拿掉按了沒作用的，不拿掉真的送得到的**

「按下去的預期」那一格實作時定下（issue 原文要求實作時決定）：

* 畫面上的「失聯」是**後端收不到遙測**。返航／降落走的是**另一條路**——指令服務自己的埠
  （代理把飛控的訊息同時送到兩個埠，兩條各自會斷）。
* 所以判準用事實：`cmdAlive` ＝ 指令服務的 router 活著、而且 **5 秒內還收到這台機**
  （healthz 的 `age_s`；每 3 秒問一次，最壞 8 秒）。
  * 通 → 留下兩顆鈕，標題寫「**遙測斷了——但指令還送得到**（指令服務 N 秒前還收到這台機）」
  * 不通 → **沒有按鈕**，標題「失聯——指令也送不到這台機」，下面一句說指令服務多久沒收到、
    「返航與降落按了也送不到，所以不放按鈕——要處置請用實體遙控器」
* 050 需求 3 的「斷在哪一段」那幾行保留（代理還連著／飛控序列埠斷了／代理也聯絡不上）。

這與使用者拿掉按鈕的理由一致（「按了也沒有作用」），只是不把**真的有作用**的那次 RTL 一起拿掉。

### 真畫面翻出的第二處

驗證時看到同一個面板上**還有一塊**「意圖通道斷了——只剩返航與降落」（`admitted_offline`，
040 A2 的 09-04 裁定），**掛著同樣兩顆送不到的鈕**——一塊說「只剩返航與降落」、一塊說
「按了也送不到」。處置：遙測也斷時這一塊不顯示（下面那塊已經講完）；遙測還在時照舊，
但按鈕同樣要 `cmdAlive`。

**沒有實機重現的那一支**：「遙測斷、指令還通」。要單獨擋掉後端的遙測埠，而 Pi 與地面站上
都沒有可用的 iptables。邏輯只有一個布林（`cmdAlive`），但**按鈕在那個情況下真的送得到**
這件事沒被驗過。

**刻意沒動的**：標題列的「⏷ 原地降落」。09-07 使用者裁定它是系統內最高優先的指令、
「不歸上面那條規則管」，失聯時它一樣送不到——要不要比照，是另一個裁定。
