## 三、校準 vs 機械——**機械，而且校準修不了**

**校準問題的形狀是穩定的偏差**（水平歪、往某個方向漂）。這裡事發前 4 秒
三軸都跟到 1–4° 以內——**校準是好的**。

變故是**瞬間**的（1467.71 → 1467.91，200 毫秒）：

```
陀螺 Y   0.03 → -1.90 → -22.67 rad/s   （-22.67 rad/s ＝ -1300°/s）
加速 Z  -9.9  → -8.0  → +15.9 m/s²
震動 X   6.4  →  7.5  →  28.7（加速度計開始截波）
```

調參或校準做不出 1300°/s 的角速度，那是**推力突然變化或撞擊**。

**然後控制器把差動開到底、維持三秒，姿態照樣越來越差**：

```
1468.01 [1150, 1949, 1235, 1917]
1468.61 [1592, 1727, 1150, 1681]   ← M2 釘在 1949、鄰邊釘在 1150
1468.91 [1651, 1949, 1150, 1754]   滾轉 111.8°
1469.11 [1410, 1150, 1528, 1333]   滾轉 -174.9°（翻過來了）
```

**M2（左後）從變故開始就被命令到最大並維持到最後。** 如果那顆有出力，
最大推力應該要把旋轉拉住——它沒有。**指向左後那支機臂**：
馬達、電變、螺旋槳或固定件。

**震動在事發前就一路在爬**（同一顆 IMU）：

```
地面 0.9  →  起飛後 3.5  →  4.2  →  6.1  →  8.1  →  事發 28.7（截波 8）
```

## 誠實邊界

* **分不出「M2 掉推力」與「撞到東西」**——兩者都會給出瞬間角速度＋加速度尖峰。
  1.5 m 的空曠場地撞到東西的機率低，而且震動在事發前就在爬，
  所以偏向前者，但這是推論不是證明。
* **懸停期四顆的平均**（M1 1517／M2 1482／M3 1522／M4 1550）差到 68 µs，
  但那段同時在加速與轉向，分不出多少是配平、多少是指令。
* **`INS_LOG_BAT_MASK = 0`**，所以沒有原始 IMU 批次資料可以做 FFT
  ——**下次飛之前把它設成 1**，震動的頻率能直接指出是哪一顆的哪一階。
